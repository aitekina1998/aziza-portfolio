# Aziza Aitekina — personal website

A responsive, static portfolio built with HTML, CSS and JavaScript. No build tools required.

## Publish with GitHub Pages
1. Create a public repository named `aziza-portfolio` on GitHub.
2. Upload **the contents** of this folder (index.html, style.css, script.js and assets/), not the outer folder or ZIP itself.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch.
4. Choose `main` and `/ (root)`, then Save.
5. Visit `https://YOUR-USERNAME.github.io/aziza-portfolio/`.

Replace the email and adjust any personal facts before publishing. Photos and certificates are public when uploaded to a public GitHub repository. The research demo is an external link.
